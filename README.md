🏨 Hotel Reservation System
📌 معرفی پروژه

این پروژه یک وب‌سایت کامل مدیریت و رزرو هتل است که امکان مشاهده اتاق‌ها، رزرو برای بازه‌های زمانی مختلف، پرداخت آنلاین و مدیریت رزروها را فراهم می‌کند.
سیستم به‌صورت دیتابیس‌محور و مقیاس‌پذیر طراحی شده و تمام فرآیند رزرو از انتخاب اتاق تا پرداخت و کنسلی را پوشش می‌دهد.
✨ امکانات اصلی

نمایش لیست اتاق‌ها به همراه جزئیات و تصاویر

امکان رزرو اتاق برای تاریخ‌های دلخواه

بررسی خودکار ظرفیت و در دسترس بودن اتاق‌ها

سیستم کامل سبد خرید (Cart System)

امکان پرداخت آنلاین

امکان لغو (Cancel) رزرو مطابق قوانین تعریف‌شده

مدیریت رزروهای کاربران

پنل مدیریت قدرتمند با استفاده از Django Admin

🛠️ پنل مدیریت (Admin Panel)

افزودن، ویرایش و حذف اتاق‌ها

بارگذاری تصاویر برای هر اتاق

تعریف قیمت اتاق‌ها

مدیریت رزروها و وضعیت پرداخت

مدیریت کاربران و دسترسی‌ها

🧩 معماری و منطق سیستم

طراحی ماژولار و تفکیک لایه‌ها (Models, Views, Templates)

بررسی تداخل تاریخ‌ها برای جلوگیری از رزرو هم‌زمان

محاسبه خودکار قیمت نهایی بر اساس تعداد شب‌های اقامت

ذخیره وضعیت پرداخت و رزرو در پایگاه داده

پیاده‌سازی فرآیند لغو رزرو با به‌روزرسانی وضعیت اتاق

💻 تکنولوژی‌های استفاده‌شده

Backend: Django

Frontend: HTML, CSS, JavaScript

Database: PostgreSQL / MySQL

Authentication: Django Auth System

Admin Panel: Django Admin

Payment: اتصال به درگاه پرداخت

🚀 ویژگی‌های قابل توسعه

افزودن سیستم تخفیف و کد هدیه

پنل مدیریت اختصاصی به‌جای Django Admin

سیستم امتیازدهی و نظرات کاربران

گزارش‌گیری و داشبورد مدیریتی

API برای اپلیکیشن موبایل

📂 نحوه اجرا پروژه
git clone https://github.com/mobin9229/Hotel/tree/master
cd hotel-reservation-system
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

👤 درباره پروژه

این پروژه با هدف نمایش توانایی در طراحی سیستم‌های رزرو، مدیریت داده، پیاده‌سازی منطق بیزینسی و توسعه بک‌اند توسعه داده شده و مناسب استفاده در پروژه‌های واقعی است.
